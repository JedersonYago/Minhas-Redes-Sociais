# 🌐 Minhas Redes Sociais

Uma página web desenvolvida para reunir minhas principais redes sociais em um único lugar.

## 🚀 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar meus conhecimentos em **HTML e CSS**.

A aplicação apresenta uma interface simples e moderna, onde é possível acessar diferentes redes sociais através de links.

## ✨ Funcionalidades

- 🔗 Links para redes sociais
- 🎨 Design moderno

- ✨ Efeitos de hover
